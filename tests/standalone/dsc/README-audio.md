# DSC MF/HF audio FSK experiment

Run `DSDR_TEST_SILENT_AUDIO=1 tests/standalone/dsc/run_audio.sh` from the repository root. The standalone test opens no audio device and builds only in `build/dsc-standalone`. It compiles the reference files directly from the external OnAir checkout, configurable with `ONAIR_ROOT`. The bit-level test remains `tests/standalone/dsc/run.sh`.

`FskAudioRx` accepts mono float audio at exactly 24 kHz, with known centre 1700 Hz, 170 Hz shift, nominal 100 baud; high tone means B and low tone means Y. Two half-bit quadrature correlators form an energy discriminator. A transition-driven phase loop places the hard decisions for the existing distress nucleus, which accepts both polarities. This is an experimental, fixed-frequency front end, not an automatic signal finder, resampler, VHF receiver or complete DSC implementation. No IQ input, SDR session, actual worker, hardware, real audio, or audio-device output is tested.

The independent test oscillator generates continuous-phase tones from independently built bit fixtures. OnAir receives the same real samples as the real part of its 24 kHz complex input, with its FskSlicer centre fixed at 1700 Hz, followed by its original two-polarity DSC bit decoder. Test cases use Gaussian noise sigma 0.02 with signal amplitude 0.65; sample-clock conditions represented by 99.9, 100 and 100.1 baud; frequency offsets -10, 0 and +10 Hz; both polarities; block sizes 1, 137, 357, 4096; interruption/reset followed by a second call; silence and deterministic noise-only input. All nine rate/offset combinations decoded the expected distress body in the local path and expected MMSI with ECC in OnAir. These bounded synthetic cases do not establish sensitivity, clock capture limits, real-world performance or equivalence over other signals. The OnAir reference output is a decoded call, not the actual bitstream output compared bit by bit.

Worker contract: one instance is confined to one worker thread; serialize `process()` and `reset()`, keep the callback nonblocking, and provide bounded input/result queues externally. Invoke reset before the first sample following any dropped block, source/rate change, retune, or restart; stop the worker and drain/invalidate callbacks before destroying state. There is no internal queue, backpressure, timestamp, dropped-sample detector or thread safety. DSP and callback execute synchronously in `process()`; no hard real-time or throughput guarantee is asserted. The bit decoder can allocate, so this code must not run on a real-time audio callback without further work. Configuration must be verified before feeding: unsupported rates and tuning are not detected.

The A/B binary incorporates OnAir marine DSP, DSC and MMSI sources by reference at build time. It prints the attribution “Based on OnAir by Kristijonas Adomaitis - https://on-air.dev”.
