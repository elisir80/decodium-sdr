# POCSAG IQ receiver experiment

`src/dsp/PocsagIqReceiver.{h,cpp}` is an optional, standalone RX chain: frequency translation of complex float IQ, an 8 kHz-cutoff Hamming-windowed sinc low-pass, integer decimation to 48 ksample/s, phase-difference FM discriminator, then `PocsagAudioDecoder` and `PocsagDecoder`. Pass the centre frequency of the wanted channel relative to the input IQ centre as `channelHz`; positive frequencies are positive complex phase rotation. Tune the actual receiver and configure the relative offset correctly. Configure explicitly for 512, 1200 or 2400 baud and a sample rate of 48 ksample/s times an integer from 1 to 32 (up to 1.536 Msample/s). Rates such as 2 Msample/s and rates not divisible by 48 kHz are unsupported. The channel centre must leave more than 12 kHz to the input Nyquist edge. No AGC, squelch, resampling of arbitrary rates, automatic channel detection, baud detection or deviation calibration is included.

Configure off the hot path. `process()` is synchronous, as is the decoded-message callback; call it from a worker, not the UI or a real-time audio callback. It consumes the input directly without retaining the caller's buffer; the owner must serialize configure/reset/process and keep callback context alive. Reset after retunes, sample gaps or changes of source. Non-finite IQ resets the state. The filter maintains state across chunks and does not emit a partial page on reset. Processing costs and deadline behavior have not been benchmarked. Exact sync, BCH miscorrection and absence of message CRC remain as documented in `pocsag-standalone.md`; output is not authenticated.

## Repeatable test

```sh
DSDR_TEST_SILENT_AUDIO=1 TMPDIR=/Volumes/Projects/decodium-sdr/build c++ -std=c++17 -O2 -Wall -Wextra -Werror -Isrc src/dsp/PocsagDecoder.cpp src/dsp/PocsagAudioDecoder.cpp src/dsp/PocsagIqReceiver.cpp tests/standalone/pocsag/test_iq.cpp -o build/pocsag-iq-test
DSDR_TEST_SILENT_AUDIO=1 ./build/pocsag-iq-test
```

A separate test modulator integrates the phase of a synthetic rectangular 2-FSK signal at +/-4.5 kHz deviation, using a protocol-shaped test bitstream; it does not call the receive filter or discriminator. The deterministic matrix compares three rates (48, 96, 192 ksample/s), three baud rates, channel centres -8/0/+8 kHz, residual frequency errors -600/+600 Hz, independent Gaussian IQ noise standard deviation 0/0.10 per component at unit signal amplitude, and chunk sizes 1/257/whole stream: 324 executions. All require exact expected text, RIC and function, and zero BCH corrections. Additional cases cover inverted polarity and a synthetic continuous interferer 20 kHz from the carrier at amplitude 0.35, wrong baud, noise alone, invalid configurations, and reset mid-message. The interferer tests do not measure a filter rejection curve. Seeds and test text are synthetic; the noise levels do not establish receiver sensitivity or RF SNR. No recording, actual SDR hardware, channel fading, clipping, sample drops, arbitrary sample-rate conversion, real-time throughput, GUI or OnAir comparison has been tested.

Additional synthetic A/B cases at 960 ksample/s and 1.536 Msample/s use 1200 baud, a 100 kHz channel offset and two chunk sizes. An optimized local run processed 1.87 seconds of generated input in approximately 0.09 and 0.15 seconds respectively. This isolated timing is not an end-to-end real-time or hardware guarantee.
