# DECODIUM SDR 1.2.6 «Baird»

Release 1.2.6 aggiorna il codebase con il fix del profilo CAT RTL-SDR: la
porta seriale selezionata viene ora dichiarata automaticamente al backend,
senza richiedere il click su «SALVA PROFILO CAT». Il modello della tendina
conserva il nome reale della porta e impedisce che un refresh riutilizzi una
porta precedente.

La release include gli installer macOS Intel e Apple Silicon, le AppImage
Linux x86_64 e ARM64 e il pacchetto Windows x64 prodotti dalla pipeline di
release.
